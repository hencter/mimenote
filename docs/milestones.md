## M1 范围冻结（本次交付）

**做**：
- pnpm + Cargo 双 workspace，`mn-core` 纯逻辑库与 Tauri 应用分层
- `mn-core`：路径防护、原子写、迭代式 Vault 扫描、回收站、文本统计（含单元/集成测试）
- Tauri 应用：会话状态、12 个 IPC 命令、稳定错误码、CSP、能力声明最小化、日志落盘、命令行打开 Vault
- 前端：领域层（树/虚拟列表/EOL/Markdown 净化）、状态层、IPC 可替换适配器
- UI：Vault 门闸、虚拟化文件树（键盘导航 + 过滤）、CM6 编辑器（自动保存/冲突横幅）、实时预览、状态栏（字数/保存耗时/主题切换）、可拖拽分栏
- 内置扩展点：命令注册表 + 快捷键、JSON 主题（CSS 变量）、Vault CSS 片段
- 测试：Rust 单元/集成 + TS 领域层单测 + 组件集成（jsdom）+ **两层 E2E**（真实二进制 / 真实 Chromium）

**不做**（推迟，见 architecture.md §8）：双链/反链/标签/搜索/图谱/插件/同步/内嵌图片。
