# 设计 02：MimeNote 模板语法（`@` 记号）

- 状态：**已定稿，进入实现**（Lead 定规格；实现由 `template-syntax` 队友负责，对应 ADR-0056）
- 日期：2026-10-12
- 前置：ADR-0009（Live Preview）、ADR-0030（显示名）、ADR-0044（时间挂钩）、wiki-complete（`[[` 补全）

## 0. 用户的原话与它指向的设计

> "模板这里我希望你构建一个语法！一个全新的适配于 MimeNote 模板语法，足够简单，快捷，
> 方便用户 type 出来。之前我们一直有双链，但是 `[测试]` 方括号这个东西不管是在 Obsidian
> 还是 MimeNote 都没有一个很好的应用。"

要点拆开就是三条硬约束：

1. **不要方括号**。方括号在 Markdown 里已经被 `[文字](地址)` 与 `[[双链]]` 占满，
   再塞一套模板语义进去，人读不出来、解析器也要打补丁（这正是它在两个产品里都没立住的原因）。
2. **要"type 出来"**：不能有配对结束符 —— 每写一个记号都要求再敲一次收尾，等于把成本翻倍。
3. **要简单**：v1 不做编程语言。没有条件、循环、嵌套、过滤器。

## 1. 记号选择：`@`

| 候选 | 否决理由 |
| --- | --- |
| 方括号 `[x]` / `{{x}}` / `${x}` | **有配对结束符**（要敲两次），且与链接语法撞车 —— 用户明确点名的问题 |
| `%x%` | 仍有配对；`%` 在美式 QWERTY 上是 `Shift+5`（右手），比 `@` 贵 |
| `/x` | 无需 Shift，但**散文里 `/` 太常见**（路径、日期 `2026/10/12`、`and/or`）。作为**自动补全触发器**会不断误触发 |
| **`@x`** | `Shift+2`（左手，一键可达）；**无结束符**；散文里 `@` 罕见，作为触发器安静；语义天然读作"在这里插入一个东西" |

**边界规则（这两条同时成立才算记号，因此邮件地址绝不被吃）**：

1. `@` 的左邻**不能是 ASCII 词内字符**（`[A-Za-z0-9._+-]`），即：左邻可以是行首、空白、
   标点 —— 也包括**中文标点与汉字**。于是 `mail@example.com`、`a.b@today`、`2026@today`
   都不是记号，而 `会议记录：@cursor`、`正文，@today`、`今天@cursor完成了` 都成立。
   > 为什么是"否定式（排除 ASCII 词内字符）"而不是"枚举式（只认行首/空白/几个括号）"：
   > 中文没有空格，枚举式会把中文标点全部否掉，这个语法在中文里就几乎不可用 ——
   > 而中文正是本应用的首要场景。否定式是枚举式的**超集**：枚举式认可的一切它都认可。
   > 已知代价（刻意保留、已钉断言）：`团队@today` 会展开（用户真要写字面量时用 `@@`）。
2. `@` 后的名字必须**命中内建变量表**（大小写不敏感）。未知名字 → **原样保留**，
   绝不静默吞掉用户输入。

转义：`@@` → 字面量 `@`（只此一条；`\@` 不是转义，避免两套转义规则互相打架）。

## 2. 语法（BNF 级别，全文就这么多）

```
记号      ::= "@" 名字 [ "=" 参数 ]
名字      ::= 内建变量名（大小写不敏感）
参数      ::= 到"行尾 | 空白"为止的任意文本，允许中文
内建变量  ::= today | now | date | time | title | filename | path | vault
            | cursor | uuid | clipboard | prompt
```

- **没有结束符**：记号在遇到空白或行尾时自然结束。
- **参数里不能有空格**（中文标题可以，中文没有空格）。需要空格的场景写成 `@prompt` 由对话框输入。
- **一律纯文本替换**：展开后不留任何标记（不是"渲染成组件"，源码里看到的就是最终值）。

## 3. 内建变量（v1 全集）

| 记号 | 展开为 | 备注 |
| --- | --- | --- |
| `@today` | `2026-10-12` | 本地日期 |
| `@today=YYYY年M月D日` | `2026年10月12日` | 参数是**模式串**（见 §4） |
| `@now` | `2026-10-12 20:50` | 本地日期+时间 |
| `@date=YYYY-MM-DD` | 同 `@today=…` | `@date` 是 `@today` 的显式别名（更好读） |
| `@time` | `20:50` | |
| `@title` | `我的笔记` | 按 ADR-0030 的 `displayName`（不含 `.md`） |
| `@filename` | `我的笔记.md` | 真实文件名（含扩展名） |
| `@path` | `folder/我的笔记.md` | Vault 内相对路径 |
| `@vault` | `mimenote-vault` | Vault 目录名 |
| `@cursor` | （空串） | **光标落点**；一篇模板里最多一个，多余的原样保留 |
| `@uuid` | `3f2a…`（v4） | 文件名/附件名用 |
| `@clipboard` | 当前剪贴板纯文本 | 拿不到时留空并提示 |
| `@prompt` | 创建时弹一次输入框，返回用户输入 | `@prompt=标题` → 对话框标题叫"标题" |

## 4. 模式串（只有这 8 个记号，够用且不必查表）

`YYYY` 四位年 · `YY` 两位年 · `MM` 两位月 · `M` 月 · `DD` 两位日 · `D` 日 ·
`HH` 两位时 · `mm` 两位分 · `ss` 两位秒 · `dddd` 星期几（中文） · `ddd` 星期几（简写）

- 为什么不用 strftime（`%Y-%m-%d`）：`%` 要按 `Shift+5`，而且 `%Y` 对非程序员不直观；
  为什么不用 Go 的 `2006-01-02`：那是"用一个具体日期当格式"，反直觉且容易写错。
- 默认（不带参数）：`@today` = `YYYY-MM-DD`，`@now` = `YYYY-MM-DD HH:mm`，`@time` = `HH:mm`。

## 5. 两个上下文，一套判据

**判据只有一份**：`domain/template/scan.ts` 的 `scanTemplateTokens(text)` 返回
`{ start, end, name, argument, raw }[]`。编辑器插件与模板展开器**都**消费它 ——
绝不允许两处各写一遍正则（这正是 `[测试]` 在别处烂掉的方式）。

### 5.1 模板文件（新建笔记时整篇展开）

- 位置：`<Vault>/.mimenote/templates/*.md`（目录可在配置 `templates.dir` 里改）。
- 入口：`template.newFrom`（`Mod+Shift+N`）选模板 → 展开 → **落到"新建笔记"的目标目录**
  （当前选中的目录；没有选中时是 Vault 根，与 `Mod+N` 完全同一条规则）并打开。
  > 与本文档初稿的一处**有意修正**：初稿写"默认落到收件箱"。实现时改为跟随"新建笔记"的落点，
  > 理由是**语义**：模板是"我要写这一类笔记（会议/日记/周报）"，落点应当跟随当前上下文；
  > 而"我知道要记、但还没决定放哪"是收件箱的语义，那一件事已经由 `inbox.capture`
  > （`Mod+Shift+I`）承担。把模板强行塞进收件箱会让"结构化笔记"和"待处理条目"混在一起，
  > 反而破坏 §3 的"未整理 = 位置"这条判据。
  > 对话框将来要提供目标目录切换时，默认值仍是这一条。
- **frontmatter 也参与展开**：模板可以写 `created: @now`、`title: @title`。
- 模板文件本身**不在文件树里显示**（`.mimenote/` 已被扫描器忽略），模板清单由宿主的
  `templates_list` 提供（只认 `.md`）；目录不存在或为空 → 对话框显示空态并说明去哪儿放文件。

### 5.2 编辑器内联（写的时候直接敲）

- 输入 `@` 弹补全（与 `[[` 完全同一套交互：同一份键盘处理、同一份主题、同一个候选面板），
  候选里显示**展开后的真实值**（`@today` 那一行右边直接显示 `2026-10-12`）——
  用户不必记名字。
- 选中后**直接插入展开值**（`@today` → `2026-10-12`），而不是插入记号。
- `@prompt=…` 例外：插入字面记号，创建笔记时再问（编辑器里弹对话框会打断写作）。
- 代码上下文（围栏代码块、行内代码）内**不触发**：与行内 `#标签` 的判据同一条纪律。

## 6. 错误与边界（每一条都要有明确的界面表现）

| 情况 | 行为 |
| --- | --- |
| 未知名字（编辑器内） | 补全列表不出现；已输入的 `@foo` 原样保留、不加装饰（不标红 —— 它可能只是邮箱/用户名） |
| 未知名字（模板展开时） | 原样保留 + 展开结果里列出"未识别的记号"，**不阻断**创建 |
| `@cursor` 出现多次 | 第一个生效，其余原样保留并提示 |
| 模板里没有任何 `@cursor` | 光标落在**文档末尾** |
| `@clipboard` 拿不到内容 | 空串 + 一条非阻断提示 |
| 模板文件为空 | 允许（等价于新建空笔记） |
| 模板文件是目录 / 不存在 | 命令置灰并给出原因（沿用 `unavailableReason` 的纪律） |

## 7. 明确不做（v1 的边界，写下来防止膨胀）

条件、循环、嵌套记号、自定义函数、参数里的空格、跨文件包含、模板继承、变量定义与复用。
—— 这些都是"编程语言"的开始，与本设计的第 0 节第 3 条直接冲突。要加，必须先证明
"有一个真实使用场景，只有这 12 个记号表达不了"。

## 9. 验收（进入测试阶段的判据）

1. 三种内建格式（无参 / `=YYYY年M月D日` / `=ddd`）展开正确，且**与系统时区一致**。
2. `mail@example.com`、`@username`、`@@` 三种输入**都不被误伤**（各自的断言）。
3. 同一个 `scanTemplateTokens` 同时驱动补全与展开（改动判据 → 两处行为一起变）。
4. 模板里 `@cursor` 让光标落在指定处；无 `@cursor` 落在末尾。
5. 展开是**纯文本**：源码里就是最终值，撤销一次回到插入前。
6. 代码块内的 `@today` 保持字面量。
