# ADR-0051：UI 走查批（品牌标识、工具栏收敛、最近 Vault 弹层、设置窗口）+ 图谱不降级

- 状态：已采纳（已交付）
- 日期：v0.3.0 之后（UI 走查轮）
- 相关：ADR-0038（标题栏退役）、ADR-0034（顶行合并）、ADR-0027（最近打开的 Vault）、
  ADR-0042（只引行为层）、ADR-0046（Maple Mono）

## 背景

一次界面走查发现四处"控件比内容抢眼"：没有正式标识（门闸与设置页用的是图标库里的
一个 sparkle）、文件树工具栏把两种不同性质的按钮（对**这一篇**的操作 / 对整个**库**的
操作）挤在一行、最近 Vault 的弹层是单行 label 挤两段文字、设置页占满整窗。

## 决策

### 1. 品牌标识只住两处，且是**资产**不是图标

- `public/brand/mimenote-lockup.svg`：门闸页（库还没打开时唯一该出现的品牌面）；
- `public/brand/mimenote-mark.svg`：设置页「关于」分区的品牌块；
- 桌面应用图标随之一套重出（`src-tauri/icons/**`、`app-icon.png`）。

为什么不做成 `<Icon>`：ADR-0043 那套 `IconName` 管的是**界面图标**（16px 刻度、
`currentColor` 跟随主题）；品牌标识是要带形状与颜色、尺寸跨 52–112px 的资产，
放进图标表只会让"改主题色就顺手改了 Logo"这种事变得可能。

### 2. 文件树工具栏撤出"文档操作"，按钮带文字；**导出保留**

- 撤出「新建 / 重命名 / 移动到文件夹」：这三条是**对当前选中项**的操作，等价入口在
  文件树右键菜单、`Ctrl+N` / `F2` / `F6` 与命令面板里 —— 工具栏的定位收敛成"库与视图"；
- **`导出` 留在原位**。它是**三选一导出对话框的唯一入口**（单篇 HTML / 打印为 PDF /
  整库静态站点），而命令面板里那三条 `export.*` 是"直接执行"、不经过对话框 ⇒
  撤掉这个按钮会让那张对话框（连同它那句"链接索引还在构建，所以整库导出暂时灰着"的
  解释）在任何地方都打不开。这条是先撤后补回来的：UI E2E 的
  "整库导出静态站点：浏览器预览模式没有系统目录选择框"用例在撤掉按钮之后直接失败 ——
  **它是这一批里唯一一条"删掉入口就删掉能力"的改动，其余三条都有等价入口**；
- 保留下来的按钮从裸图标改成**图标 + 文字**胶囊（`展开 / 折叠 / 刷新 / 排序 / 打开库`），
  分隔线只留导出前面那一条：文字本来就写在 tooltip 里，而 tooltip 只在悬停时才存在；
- 排序菜单、标签过滤行、切换 Vault 的位置与行为一字未改。

### 3. 最近 Vault 弹层：两行选项 + 对勾居右

一行里放"名字 + 完整路径"两段可各自截断的文字（`grid-template-columns: 16px 1fr 16px 24px`）：
文件夹图标 / 名字与路径 / 选中对勾 / 移除 ×。当前库**不再禁用**（重选 = 无操作，
跳过切换），`Esc`、`↑↓`、移除 × 的既有语义不变。底部那一行（摘要 + 设置按钮）
改成垂直居中并加一条顶部分隔线（弹层走 Portal，不再撑高这一行）。

### 4. 设置窗口：紧凑居中 + 窄窗单列

`680×600` 上限的居中窗口（原先是铺满窗口的模态），窄于 560px 时导航转成横向排在顶部。
四个分区、所有设置项与即时生效（`Compartment` 重配置、不重建编辑器）一字未改。

## 附：本轮**没有**采纳的方案 —— 把知识图谱换成朴素 SVG 节点网络

工作树里曾出现一版"朴素节点网络"图谱（自研圆点 + 直线 + 搜索框，删除
`GraphCanvas` 的力场/卡片/HUD/连线，并把图谱的四条测试一起删掉）。它被**撤销**，理由：

1. 它会一次性抹掉 ADR-0021/0023/0025/0028/0035/0036 六份已交付决策的成果
   （自我中心子图、卡片正面是完整正文、浮动态与力度管理、连线语义分层与环向走线、
   连线与卡片共用画布），而**没有任何一份 ADR 记录这个推翻** —— 与"每个交付项
   配一份 ADR"的纪律相反；
2. 它留下 20 个孤儿模块与 2 份孤儿样式表（`force.ts` / `layout-ego.ts` /
   `edge-*` / `paint.ts` / `force-panel.css` / `graph.css`），
   `tests/stylesheets.test.ts`（"没有孤儿样式表"）本就会失败告警；
3. 命令面板里"浮窗 / 力度 / 沿环走线"那批命令会变成永远无效的按钮。

**结论**：图谱继续是 canvas 卡片（ADR-0021 起的那一套）。真要简化成节点网络，
先写一份 ADR 说清"换取什么、代价是什么、哪些命令与测试一起退役"。

## 代价与已知边界

1. 文件树工具栏少了三个可见入口（新建、重命名、移动到文件夹）：右键菜单、快捷键与命令面板
   都在，但**可发现性确实下降了**；**导出没有跟着撤**（理由与"先撤后补"的过程见 §2）——
   投影到工具栏上的东西要按"有没有等价入口"逐条判，不能按"看起来属于同一类"一起撤；
2. 品牌标识是**两条独立路径**（lockup / mark）：换 Logo 要同时换两个文件与图标集；
3. 设置窗口的 680×600 是写死的上限，窗口比这更小时靠 `max-height: calc(100dvh - 40px)`
   兜住（没有做"按窗口尺寸自适应"那套）。
