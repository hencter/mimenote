# ADR-0056：模板语法用 `@` 记号（无结束符、单份判据）

- 状态：已采纳（本次交付）
- 日期：2026-10-12（用户诉求："构建一个语法！一个全新的适配于 MimeNote 模板语法，足够简单，
  快捷，方便用户 type 出来。之前我们一直有双链，但是 `[测试]` 方括号这个东西不管是在 Obsidian
  还是 MimeNote 都没有一个很好的应用"）
- 相关：ADR-0002（Markdown 单一真相）、ADR-0004（原子写与冲突令牌）、ADR-0009（Live Preview）、
  ADR-0018（回收站）、ADR-0030（显示名不带 `.md`）、ADR-0044（frontmatter 时间挂钩）、
  ADR-0055（快捷键与配置文件）、设计 02（`docs/design/02-template-syntax.md`，本决定的完整规格）
- 前置实现：`wiki-complete`（`[[` 补全，本决定复用了它的弹层样式与键位纪律）

## 背景

模板此前只有一个空壳："从模板新建"没有可写的语法。用户的要求里藏了三条硬约束：

1. **不要方括号**。方括号在 Markdown 里已经被 `[文字](地址)` 与 `[[双链]]` 占满；再塞一套
   模板语义进去，人读不出来（`[标题]` 到底是链接、是任务、还是模板记号？），解析器也要打补丁
   —— 这正是它在两个同类产品里都没立住的原因。
2. **要"type 出来"**。每写一个记号都要求再敲一次收尾符，等于把输入成本翻倍，而模板恰恰是
   高频、短小、边写边看的东西。
3. **要简单**。v1 不做编程语言：没有条件、循环、嵌套、过滤器、变量定义。

同时有三件事让它现在能做成：`note_create`/`note_write`（唯一命名 + 原子写 + 冲突令牌）已经齐了；
`wiki-complete` 已经证明了"不抢按键的补全弹层"该怎么写；`.mimenote/` 是现成的应用私有目录
（`snippets_list` 的先例），模板因此可以存在 Vault 里而**不进文件树、不进索引**。

## 决策

### 1. 记号码是 `@`，且**没有结束符**

记号在遇到空白或行尾时自然结束（`@today`、`@today=YYYY年M月D日` 都是一个记号）。
展开一律是**纯文本替换**：结果里不留任何标记，源码里看到的就是最终值。

### 2. 两条边界规则**同时**成立才算记号

1. `@` 的左邻不能是"词里的一部分"：**ASCII** 字母/数字与 `.`、`_`、`-`、`+`；
2. `@` 后的名字必须命中内建变量表（大小写不敏感）。

于是 `mail@example.com` 里的 `@` 根本不是起点（左邻 `l`），`@username` 因为名字不认识而原样保留。
两条规则的必要性各自独立：只有第 1 条，`@username` 会被当记号然后展开成空白；只有第 2 条，
邮件地址的 `@example` 会变成一条"未识别的记号"提示（正文没坏，但界面在说废话）。

### 3. 为什么边界是**否定式**（"左邻不是字母/数字/`.`/`_`/`-`/`+`"），而不是枚举式

规格 §1 的括号里写的就是这句否定式；它的前半句（"必须是行首、空白或 `（(【[{` 之一"）是**枚举式**。
两者在邮箱这类输入上结论一致，但枚举式会否掉中文标点：`：`、`，`、`」` 都不在那六个字符里，
于是 `会议记录：@cursor`、`正文，@today` 都不成立 —— 而中文没有空格，这两个写法恰恰是最自然的那个。
这个语法的主要语言场景是中文，被否掉就等于不可用。**见"替代方案"表**。

否定式是枚举式的**超集**（规格认可的一切它都认可），所以它没有放宽"什么算记号"以外的任何行为。

排除集合里**只收 ASCII**、不含汉字：这里说的"字母"是邮件地址那类词内字符（`字母@域名`），
而 `今天@cursor完成了` 这种行内落点是 `@cursor` 最正常的用法之一。代价是 `团队@today` 会展开
（`today` 是内建名）—— 这个已知代价写进了 `scan.ts`、单测断言与设计 02。

### 4. 12 个内建变量、11 个模式串记号，全部写在一张表里

`today | now | date | time | title | filename | path | vault | cursor | uuid | clipboard | prompt`
（大小写不敏感）。模式串只有 `YYYY YY MM M D DD D HH mm ss dddd ddd`，一次正则替换搞定。

`title` / `filename` / `path` 求的是**这篇新笔记自己**的名字，且标题一律按 ADR-0030 的
`displayName` 口径算（不含 `.md`）—— 展开器只消费调用方算好的值，**不碰路径字符串**，
否则"显示名怎么算"就有了第二份实现。

### 5. 判据只有一份：`domain/template/scan.ts`

`scanTemplateTokens(text)` 返回 `{ start, end, name, argument, raw }[]`，**编辑器补全与模板展开器
都只消费它**。同一个模块同时导出"未识别的记号"与"`@@` 转义点"，以及给编辑器用的
`templateDraftAt`（光标处那条还没打完的记号）—— 它们共用同一份词法与围栏状态机。

这是设计 02 §5 的硬要求，理由就是 `[测试]` 烂掉的那种方式：两处各写一遍正则，改一处另一处不变。

### 6. 代码上下文里 `@` 保持字面量，判据是**纯文本**的

围栏代码块（含开/闭围栏那一行）与行内代码里的 `@today` 不是记号。判定不 import CodeMirror：
`domain/` 不认编辑器，而展开器（纯函数）与补全器必须共用同一份判据。围栏规则与
`domain/outline.ts` 逐字一致（同种字符、长度不短于开始才算结束）；行内代码用 CommonMark 的
"反引号串长度相同才配对"，**未闭合**的一串算到行尾（用户正打到一半时那本来就是代码）。

**不跳过 frontmatter**：模板的 frontmatter 也参与展开（`created: @now`）。这与 `[[` 补全跳过
frontmatter 的口径故意不同 —— 那里 frontmatter 里不该有链接，这里正是用户要写记号的地方。

性能上，`templateDraftAt` 先只对光标那一行做词法（O(行长)），只有真摸到 `@` 才算代码区间，
于是"每次按键"的常见情形不付任何与文档长度相关的代价（`wiki-complete` 对 `[[` 的同一条纪律）。

### 7. 只有 `@@` 这一种转义，`\@` **不是**

`@@` → 字面量 `@`。刻意不加反斜杠转义：多一种转义就多一条"哪些字符能转义、转义后还算不算记号"
的规则要维护，而 v1 的表达式里没有需要转义的东西（没有结束符，也就没有"写不出来的字面量"）。
`\@today` 里的 `@` 仍是记号、`\` 原样留在正文里。

`@@@today` = 一个转义 + 一个真假记号：`@@` 吃掉两个字符后，第三个 `@` 的左邻是 `@`
（不在词内字符集合里），仍按左邻规则判成记号起点。这条钉在单测里。

### 8. 两个上下文，两套落点

| 上下文 | 入口 | 行为 |
| --- | --- | --- |
| 模板文件（`<Vault>/.mimenote/templates/*.md`） | `template.newFrom` → 展开 → 落到目标目录并打开 | frontmatter 也展开；`@cursor` 定光标落点（最多一个，没有则落**文档末尾**） |
| 编辑器内联 | 敲 `@` 弹补全（与 `[[` 同一套交互/主题/键位） | 候选右侧显示**展开后的真实值**；确认后插入**展开值**，不是记号 |

两条仅有的例外：`@prompt` 在编辑器里插入**字面记号**（创建时再问 —— 编辑器里弹输入框会打断
写作），`@cursor` **不进编辑器候选**（用户的光标本来就在那儿，而它的展开值是空串，
选中它等于把刚敲的四个字删掉）。`@clipboard` / `@prompt` / `@uuid` 的候选右侧给占位说明
而不是假值：剪贴板要异步读、prompt 要等回答、uuid 每次都不同。

时间值取**本地**时区（`getFullYear`/`getHours` 那一组，不是 `toISOString`）——否则东八区
早上 8 点前会看到昨天的日期。一次展开取**一个**时间快照，同一篇里的两个 `@now` 因此必然一致。

### 9. 错误一律"不阻断、但说出来"

| 情况 | 行为 |
| --- | --- |
| 未知名字（编辑器内） | 补全列表不出现；已输入的照原样留着、不加装饰（它可能就是邮箱/用户名） |
| 未知名字（展开时） | 原样保留 + 结果里列出"未识别的记号" |
| `@cursor` 多个 | 第一个生效，其余原样保留并提示 |
| 没有 `@cursor` | 光标落文档末尾（`cursor === null`，不是 0） |
| `@clipboard` 拿不到 | 空串 + 非阻断提示 |
| 模板目录不存在 / 空 | 允许（空态由对话框呈现，不是错误） |

## 替代方案

| 方案 | 否决理由 |
| --- | --- |
| 方括号 `[x]` | 与 `[文字](地址)`、`[[双链]]`、任务列表撞车；用户点名否决的正是它（读不出、解析器要打补丁） |
| `{{x}}` / `${x}` | **有配对结束符**：每写一个记号要敲两次，与"type 出来"直接冲突；`{{` 在中文输入法下还要切形状 |
| `%x%` | 仍有配对；`%` 在美式 QWERTY 上是 `Shift+5`（右手），比 `@`（`Shift+2`，左手）贵 |
| `/x` | 无需 Shift，但散文里 `/` 太常见（路径、`2026/10/12`、`and/or`），作为**自动补全触发器**会不断误触发 |
| 枚举式边界（左邻必须是行首/空白/`（(【[{`） | 否掉中文标点：`会议记录：@cursor`、`正文，@today` 全部失效。中文没有空格，这等于让语法在主要场景里不可用（详见决策 §3） |
| 边界收 `\p{L}`（汉字也算词内字符） | 会否掉 `今天@cursor完成了`；而它想防的 `用户@example.com` 靠"名字必须命中内建表"就已经原样保留了 —— 换来的是更窄的可用面、没有多挡住任何真实输入 |
| 加 `\@` 反斜杠转义 | 多一条"什么能转义、转义后还算不算记号"的规则；v1 没有结束符，没有非转义不可的字面量 |
| 模式串用 strftime（`%Y-%m-%d`） | `%` 要按 `Shift+5`，且 `%Y` 对非程序员不直观 |
| 模式串用 Go 的 `2006-01-02` | "用一个具体日期当格式"反直觉、容易写错（为什么是这一天？） |
| 模式串用 `Intl.DateTimeFormat` | 结果依赖运行时 ICU 数据，同一模板在不同机器上可能给出不同语言；中文单语产品里确定性更重要 |
| 用语法树（lezer）判代码上下文 | `domain/` 不认编辑器，而展开器是纯函数、必须与补全器共用同一份判据；纯文本围栏判定还与 `domain/outline.ts` 同源 |
| `@cursor` 也进编辑器候选 | 它的展开值是空串，选中即把用户刚敲的字删掉（与"绝不静默吞掉用户输入"相悖） |
| 在编辑器里弹 `@prompt` 输入框 | 打断写作；且展开必须在创建那一步一次问完（答案先收集、再同步展开），否则会出现"笔记已建、内容未定"的半途状态 |
| 模板放普通目录（进文件树） | 模板不该出现在文件树、索引与搜索里；`.mimenote/` 是现成的应用私有目录（`snippets_list` 先例） |
| 引入 fuzzy 匹配库 | 仓库依赖逐个登记理由与许可证（`docs/dependencies.md`）；`features/palette/match.ts` 的子序列匹配只有十几行，且与命令面板/`[[` 补全手感同源 |

## 影响

**新增**：`domain/template/{builtins,scan,expand}.ts`、`features/editor/cm/template-complete/**`、
`features/template/**`、`state/template-store.ts`、本 ADR、设计 02、
`tests/template-{scan,expand,complete}.test.*`。

**复用（一个字节都没改）**：`wiki-complete/theme.ts` 的类名与 `EditorView.theme`（模板补全的弹层
与 `[[` 补全长得一样、键位一样）、`note-path.ts`（分栏下"我这一格是哪篇"）、
`domain/paths.displayName`（标题口径）、`app/actions.openNote`（打开笔记只有一条路径）。

**宿主新增一处**：`templates_list(dirRel)` 命令 + `ipc.templatesList` + `TemplateFile` DTO
（与 `snippets_list` 同构；只认 `.md`、走 `path_guard`、目录不存在返回空数组）。
它不是通用"列目录"接口 —— 模板目录在 `.mimenote/` 下，扫描器看不见它，
因此"列出模板"这件事必须有宿主能力，且必须保持"不进文件树/索引/搜索"这条性质。

**Lead 接线**：`app/builtin-commands.ts` 登记 `template.newFrom` → `useTemplateStore.getState().openPicker()`；
`App.tsx` 挂 `<TemplatePickerDialog />`。

**已知边界**：

- `团队@today` 会展开（决策 §3 的代价，已钉断言）；
- `@clipboard` 依赖 `navigator.clipboard.readText()`，WebView 拒绝授权时按"拿不到"处理（空串 + 提示）；
- `@prompt` 按**标签**去重：同一个标签问一次（标签就是那个问题），不同标签各问一次且**在创建之前**一次问完；
- 编辑器里 `@` 补全插入的是展开值，因此"日期"是**写死的那一天**（模板里的 `@today` 才是每次创建时求值）；
- 落点按**精确偏移**放置（`placeCaretWhenReady`）：`line-jump.ts` 的定位器只认行，
  搜索结果够用，而 `@cursor` 可以写在句子中间，所以这里另有一份"等编辑器装上这篇文档"的循环。
