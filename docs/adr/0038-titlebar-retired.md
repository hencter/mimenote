# ADR-0038：独立标题栏退役 —— 业务控件下移，窗口按钮住进右上叶标签条

- 状态：已采纳（已交付）
- 日期：修补轮（ADR-0037 打开笔记顶掉当前标签之后）
- 相关：ADR-0017（自绘标题栏）、ADR-0029（三区）、ADR-0034（顶行合并）、ADR-0035（容器切割树）
- 来源：Issue #8「下移标题栏业务控件，取消独立标题栏视觉层」

## 背景

ADR-0017 关掉系统装饰之后，`.mn-titlebar` 是唯一的标题栏；ADR-0029 把它定型成左/中/右三区；
ADR-0034 又让标签栏与它同一行。到 ADR-0035 容器切割树之后，那一行的中区回归纯拖动区，
但**右区仍与三个窗口按钮共处一行**：Vault 统计、导出、最小化/最大化/关闭。

用户看到的界面因此始终是"标题栏 + 应用 UI"两层：最上面 36px 只为承载统计与导出，
正文与文件树被压低一整条。Issue #8 的要求是重新划分层级，而不是把标题栏调矮：

> 红框内的统计、导出等内容下移后，最上方不再保留一条单独的应用标题栏。

同时要为**后续工作区标签页**（普通 Tabs / Stacked Tabs）留出顶部空间规则：
中间区域是标签页的主要承载区域，业务控件不该占住它。

## 决策

### 1. 删除 `.mn-titlebar`，内容从窗口最顶边开始

`App.tsx` 里整条 `<header class="mn-titlebar">` 与 `styles/app.css` 的
`.mn-titlebar / __left / __center / __right / __brand / __vault / __meta` 整组删除。
`.mn-app` 仍是列方向 flex，`.mn-body` 成为第一个子项（`flex: 1 1 auto`），
于是**主体 = 窗口 − 状态栏**（原来的 36px 全数还给内容）。

### 2. 业务控件各自归位（下移，而不是换个地方挤成 chrome）

| 原位置（`.mn-titlebar__right` / `__left`） | 新位置 | 理由 |
| --- | --- | --- |
| Vault 统计（笔记数 / 条目数 / 扫描耗时） | **状态栏**（本来就有一份，补上「已截断」） | 低视觉权重、不抢标题/标签注意力；状态栏那一份从此是唯一一份 |
| `导出` | **文件树工具栏**（`TreeToolbar` 的 actions 末尾） | 与 新建/重命名/移动/排序 同属"对文档/对库的操作"，是内容层的工具区域 |
| 品牌 + Vault 名 | **状态栏**（文件夹图标 + 库名；路径在最左） | 窗口标题（任务栏 / Alt+Tab）仍带产品名，主界面不必再挂一次 |
| 最小化 / 最大化 / 关闭 | **右上叶标签条右端**（见下） | 窗口级控件，必须常驻 |

文件树被收起时，导出仍可从命令面板触达（`export.html` / `export.pdf` / `export.site`）。

### 3. 窗口按钮住进**右上叶**标签条右端，且标签条**常驻**

`LeafTabs` 的一行分两段：

```text
┌──────────────────────── 36px 标签条 ────────────────────────┐
│ [.mn-tabs__scroll role=tablist：标签横向滚动] │ [窗口按钮槽] │
└─────────────────────────────────────────────────────────────┘
```

- 窗口按钮槽在**滚动区之外**（`.mn-window-controls` 是 `.mn-tabs` 的直接子项）：
  标签再多也挤不掉最小化/最大化/关闭，槽本身 `flex: 0 0 auto` 且竖直居中；
- 宿主的标签条**即使一条标签都没有也渲染**：否则"没有打开笔记"的空态会把窗口按钮
  一起带走。这是"空态没有标签条"（ADR-0035）之后唯一被推翻的一条；
- 宿主判据（`tree-layout.topRightLeafId`）：从树根走，**`row` 刀往右（`b`）、
  `column` 刀往上（`a`）**，不可渲染的半边直接跳过 —— 得到的就是"贴着窗口右上角"
  的那一格。按钮跟着**最右一格**走，而不是跟着主叶走：右停靠面板（链接/标签/大纲）
  的家就在主叶右边，跟主叶会让按钮停在窗口**中间**（用户反馈"放错位置了"）。
  默认布局（文件树 | 主叶、右侧面板收起）里右上叶就是主叶，所以按钮看起来仍在
  主叶标签条右端；一打开链接面板，按钮就搬到链接面板那一格。

### 4. 拖动区由标签条承担（`data-tauri-drag-region="deep"`）

没有独立标题栏之后，窗口拖动/双击最大化落在**每一条标签条**上：
`.mn-tabs` 带 `data-tauri-drag-region="deep"`，标签与按钮的点击不受影响 ——
Tauri 2.11 的 `drag.js` 会沿 composed path 自动跳过可点击元素
（`A/BUTTON/INPUT/SELECT/TEXTAREA/LABEL/SUMMARY`、`[contenteditable]`、`[tabindex]`、
`role=button|link|menuitem|tab|checkbox|radio|switch|option`），`role=tab` 的标签因此
天然是例外，不需要手写 `false`。这也解决了 ADR-0034 留下的"`deep` 会不会吞标签"的担心。

### 5. 顶部空间规则（为后续 Tabs / Stacked Tabs 留位）

- 一条标签条恒为 **36px**：滚动区吃剩余宽度（`min-width: 0`，`overflow-x: auto`），
  窗口按钮槽固定宽度；
- 按钮槽的按钮是 shadcn 风格的 **ghost icon button**（30×30、`--radius-md` 圆角、
  hover 底色，**不画边框、不画分隔线**）；槽本身不参与横向滚动，
  标签在滚动区内滚动，**永远不会钻到按钮下面**；
- **功能型标签用图标**（用户反馈"按钮不统一"）：文件 / 链接 / 标签 / 大纲是**面板开关**，
  不是文档，所以只显示图标（16px，`md` 档，与文件树工具栏同一把尺子；映射在 `LeafTabs`
  的 `MODULE_ICONS`，文字说明留在 `title` / `aria-label`）。命中区是整条标签（约 32×56），
  点图标、点标签空白、点 × 都有效；笔记标签保持"文件名 + 关闭"，两类标签一眼分得开。
  为此新增 `tag` 图标（`components/Icon.tsx`）；
- 后续"堆叠模式"要加行时，加在 `.mn-tabs__scroll` 的纵向维度上即可，
  窗口按钮槽与拖动语义都不用改。

## 代价与已知边界

1. **窗口按钮跟着最右一格移动**：打开右侧面板时按钮从主叶搬到那一格，收起再搬回来；
   把那一格拖到窗口下半部时，最小化/关闭也在下半部。这是"住进右上叶标签条"的直接代价；
   默认布局（文件树在左、右侧面板收起）下按钮就在窗口右上角，与 Windows 习惯一致。
2. **右上叶很窄时按钮可能被裁剪**：`.mn-leaf` 有 `overflow: hidden`，宿主窄于按钮组时
   按钮会被格子裁掉（右停靠面板通常 300px 上下，够用；极端布局才出现，不做浮层兜底）。
3. **拖动面积变小**：拖动区从"整条标题栏"变成"标签条的空白处 + 空态整条"。
   标签铺满时只剩 4px 上边距、标签间隙与右侧槽前的一点点空白 —— 双击最大化的目标也相应变小。
4. **空态多出一条 36px 标签条**：从前"没有打开笔记"时主叶没有标签条，现在右上叶常驻。
   这条空条就是窗口按钮与拖动区的宿主，不是装饰。
5. **导出入口跟着文件树可见性**：文件树收起时主界面没有导出按钮（命令面板仍在）。
   这是"下移到文件树工具栏"的代价，用户在本轮明确选了它。
6. **应用菜单仍在文件树格子的右下角**（ADR-0034 的决定），不受本轮影响。

## 验证

- `tests/tree-layout.test.ts`：`topRightLeafId` 的判据（row 往右 / column 往上、
  隐藏的半边跳过、全不可渲染时 `null`）；
- `tests/app-shell.test.tsx`：没有 `.mn-titlebar*`；右上叶空态标签条存在且带
  `data-tauri-drag-region="deep"`；`app.css` 里标题栏规则整组退役、窗口按钮槽的
  `flex: 0 0 auto` 契约；导出按钮在文件树工具栏；
- `tests/tabs.test.tsx`：没有笔记时右上叶（默认布局里就是主叶）标签条**仍在**（零条标签）、
  关闭全部之后同样；
- `tests/tree-host.test.tsx` / `tests/window-controls.test.tsx`：标签条结构与窗口按钮行为不变；
- `e2e/ui.e2e.test.ts`：主体 = 窗口 − 状态栏（不再减标题栏）、右上叶标签条 top = 0、
  36px 且是拖动区；
- `e2e/real-app.e2e.test.ts`：真实 Tauri 窗口里没有 `.mn-titlebar`，右上叶标签条是拖动区，
  三个窗口按钮在它的右端且最大化状态同步；**打开链接面板后按钮搬到最右一格、收起后搬回**。
