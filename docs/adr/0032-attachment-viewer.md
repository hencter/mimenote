# ADR-0032：第二类可打开的文件 —— 附件只读查看器

- 状态：已采纳
- 日期：修补轮（用户报"图片选择后无法预览"之后）

## 背景

用户报告：**文件树里点一张图片，什么都不会发生**。查下去，这不是灯箱坏了 ——
灯箱只服务**正文里**的图片（ADR-0007/0013）。真正的原因是一条用了很久的判据：

> **只有 Markdown 才是笔记。**

`features/vault/FileTree.tsx` 的点击分派就是它的直译：

```
isDir      → 展开/折叠
isMarkdown → openNote(...)
其余       → 只 select()（选中），什么都不显示
```

于是 `.png`、`.json`、`.csv`、`.toml` 全都点不开。用户同一批还提了 JSON / TOML / CSV
的预览诉求（并明确"看得舒服"就够 —— **只读**，不要求当场编辑）。

## 决策

### 1. 引入"第二类可打开的文件"，判据只有一份

新增 `domain/viewable.ts`：`viewerKindOf(relPath) → 'image' | null` 与 `isViewable()`。
文件树的点击分派、主区渲染哪个查看器、标题栏显示谁，都问它 —— **以后加一类只改这一处**
（JSON / TOML / CSV 就是下一片）。

判据里**不抄第二份扩展名名单**：图片那一支直接复用 `domain/assets.ts` 的
`isImageAssetTarget`（它与宿主 `assets.rs::ALLOWED_IMAGE_EXTENSIONS` 逐字一致）。
在别处再写一遍名单，代价是"渲染成图片却永远拿不到授权"那种最像"功能坏了"的状态。

### 2. 主区形态由 `ui-store.openedFile` 决定，**只读**、不进标签页

- `openedFile === null` → 主区是笔记（三种视图三选一，ADR-0009 一字未改）；
- `openedFile !== null` → 主区是附件查看器（`features/viewer/`，按 `viewerKindOf` 分派）。

两条纪律：

1. **不引入任何写路径**。打开一个文件不会让它变成"可编辑的文档" —— 编辑仍然只发生在
   Markdown 上（`note-store` 那条流水线：冲突令牌、原子写、索引同步）。
2. **标签页仍然只装笔记**（"我开着哪几篇笔记"是它的定义，ADR-0026）。看一张图不该冒出一个标签。

`openedFile` 是**瞬时状态**（与 `paletteMode` / `trashDialogOpen` 同类）：不进 `persist()`，
重启后不该自己弹回上次看过的那张图。

### 3. 标题栏中区改成"我正在看什么"

中区表达的本来就是"我在哪一篇"。现在它有了第二种答案，于是：

- 附件打开时中区显示**那个附件**（图标也换成文件），否则仍是当前笔记；
- 属性名 `data-note-path` → **`data-main-path`**（它现在两条路都承载，名字要对得上），
  两层 E2E 的探针 helper 一起改名 `currentMainPath`。可见文字仍然走 `displayPath`
  （图片**保留** `.png` —— 隐藏的只有笔记的 `.md`，ADR-0030）。

### 4. 图片查看器的三条纪律

1. **授权走 `asset_authorize`（逐文件）**：不新开"读文件"的 IPC，也不自己拼路径。
   越界、符号链接逃逸、扩展名不在白名单、文件不存在 —— 宿主都会跳过，这里如实说明原因；
2. **非 Tauri 环境不假装**：浏览器预览（`pnpm dev`）与 jsdom 里没有 asset 协议，
   显示一句明确的说明，而不是一个永远转圈的骨架（与预览面板对图片的姿态一致）；
3. **尺寸与大小如实**：文件大小来自条目表（`vault-store`），像素尺寸来自图片自身的
   `naturalWidth/Height`（解码完成才有，因此是"加载后补上"，不是预先猜）。

另外给了一个**适应窗口 ↔ 实际大小**的开关（图片查看器唯一需要的交互）。

### 5. 三条收口路径

查看器打开时主区不显示笔记，所以必须明确"什么时候回到笔记"：

1. **打开一篇笔记** —— `app/actions.openNote`（所有打开笔记的路径都走它：文件树、标签页、
   快速切换、反链、搜索结果）里 `closeFile()`；
2. **点状态栏的视图按钮** —— `setViewMode` / `cycleViewMode` 的语义就是"我要看笔记的
   那一种形态"，顺手关掉查看器；
3. **换 Vault** —— `App` 里按 `rootPath` 变化的 effect 关掉它：那个文件属于**上一个** Vault。

## 代价与已知边界

1. **单张图片 8 MiB 一档的上限**：超限时这里显示的是"没能拿到读取授权"的通用说明 ——
   宿主把"太大"和"越界"都归到"没返回授权"上了，要区分得让宿主把原因带回来（**待做**）；
2. **浏览器预览里看不到图**：那是环境事实，不是缺陷；真实渲染只由**应用层 E2E** 把守
   （真实 asset 协议 + `naturalWidth > 0`）；
3. **查看器是只读且克制的**：不能旋转、不能拖动平移、多张图不翻页（灯箱才有"上一张/下一张"）、
   也不把附件加进标签页或最近打开；
4. **没有"用系统程序打开"这条出口** —— 桌面应用里那是很自然的一条路（看大图、看 RAW、看视频），
   本轮没做，记录在此；
5. **目前只有图片一类**：JSON / TOML / CSV 与 frontmatter 属性面板是下一片，挂在同一根主轴上
   （`viewerKindOf` 加类型 + `features/viewer/` 加组件），不需要再动主区、标签页与标题栏的口径。
