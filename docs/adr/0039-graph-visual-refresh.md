# ADR-0039：图谱视觉方案刷新（聚光灯）与状态栏图谱按钮独立

- 状态：已采纳（已交付）
- 日期：修补轮（ADR-0038 标题栏退役之后）
- 相关：ADR-0021（卡片画布）、ADR-0023（浮动态与引线）、ADR-0025（卡片阅读）、ADR-0036（连线搬进 canvas）
- 来源：用户反馈 —— "知识图谱这个样子不是最佳方案，你得想出新的视觉方案"；
  "知识图谱独立按钮不和编辑和预览的快捷键放一块"

## 背景

图谱的功能已经很全（关系图 / 整个 Vault、浮动态、张力、引线、卡片阅读、连线语义色相），
但**视觉层级**是平的：

- 画布是一块纯色，没有参照物，"拖动/缩放"只有卡片在动；
- 所有卡片长得一样（同一圈边框、同一个标题色），当前笔记只在**位置**上居中，
  卡片本身不表达"我是谁"；
- HUD 是一块不透明的方盒，把模式、深度、统计、浮动态、图例、定位全平铺出来，
  视觉重量和画布相当，第一眼看到的是面板而不是图；
- 状态栏把编辑 / 阅读 / 图谱三个按钮放在同一组里，但前两个是"同一篇的两种呈现"，
  图谱是另一个视图。

## 决策

### 1. 画布：点阵 + 中心聚光（`canvas/paint.ts` / `graph.css`）

- **世界坐标点阵**（`paintBackdrop`，每 96 世界单位一颗点）画在所有内容之下：
  它跟着平移/缩放走，拖动时能看见"画布在动"；屏幕间距小于 22px 时整层跳过
  （缩得太小时点会糊成一片灰）。颜色走 `palette.cardBorder` + `globalAlpha 0.5`，
  换主题自动跟随。
- 画布底加一层从中心散开的极淡强调色（`radial-gradient` + `color-mix`），
  给"中心是当前笔记"这件事一个空间暗示。

### 2. 卡片：圆角加大 + 活跃光晕（`canvas/paint.ts`）

- `CARD_RADIUS` 6 → 10（与新的 HUD 圆角同一档）。
- **光晕**：当前笔记（`isRoot`）常驻一圈很淡的强调色描边（alpha 0.16）；
  悬停/选中（`focused`）时更亮（alpha 0.35）。描边画在卡片**之前**，只有外侧半圈露出来
  —— 观感是"这张卡被点亮了"，而不是"套了个框"。
- 用**描边**而不是 canvas `shadowBlur`：阴影要给 `PaintContext` 加属性、测试的假上下文
  也要扩签名；一圈低透明度描边已经足够，且完全走既有绘制原语（`roundRectPath` + `stroke`）。

### 3. HUD：玻璃浮层 + 分段控件 + 无边框胶囊（`graph.css`）

- 面板：半透明底色（`color-mix` 88%）+ `backdrop-filter: blur(10px)` + 更淡的边框 +
  圆角 10 → 14。画布透一点出来，面板不再像调试框。
- 视图切换：两个带边框的胶囊 → **分段控件**（凹槽 + 选中项浮起）。
- 开关胶囊 / 深度步进器：**去掉边框**（与窗口按钮、模块标签同一套 shadcn 语言），
  命中区靠 hover 底色表达；选中态仍是强调色实底（"现在开着吗"必须一眼看出来）。
- **DOM 结构与类名一个都没动**（`.mn-graph__hud` / `__mode--active` / `__chip--active` /
  `__slider` / `__find-input` …）：自动化与测试读的还是同一批抓手，这次只改观感。

### 4. 状态栏：图谱按钮独立成组（`StatusBar.tsx` / `app.css`）

编辑 / 阅读是一组（同一篇的两种呈现），图谱单独一组，中间一条 1px 的
`.mn-statusbar__divider`。三个按钮的 `aria-label`、快捷键（`Ctrl+E` 循环、`Ctrl+G` 直达）
与 `data-*` 一个都没变。

## 代价与已知边界

1. **点阵是每帧重画的**：视口内最多约 `(W/96+1)×(H/96+1)` 颗点（1280×800 约 126 颗），
   一颗点一次 `arc + fill`；相比卡片与连线的绘制量可以忽略，但**不是零成本** ——
   将来若把点阵密度调大，要重新量。
2. **光晕用描边模拟**：没有真正的投影/模糊，极近距离看是一圈线而不是柔光。
   要真柔光就得给 `PaintContext` 加 `shadowBlur`（并改测试的假上下文），本轮不做。
3. **HUD 仍然常驻全部控件**：这次只改了质感，没有把力度/图例/定位收进弹层 ——
   那会改变自动化与测试的交互路径（约 60 处引用），留作下一步。
4. **图谱按钮独立成组只动了视觉**：`Ctrl+E` 仍然在三个视图间循环（用户没有要求改快捷键）。

## 验证

- `tests/graph-paint.test.ts`：点阵在正常缩放画出、缩得太小时整层跳过；
  光晕的三种状态（root 0.16 / focused 0.35 / 普通卡片没有）与线宽；
  既有的绘制顺序、确定性与调色板契约不变（33 条）；
- `tests/graph.test.tsx` / `e2e/ui.e2e.test.ts`：HUD 的 DOM 与 `data-*` 抓手不变，
  图谱交互链路（模式切换、深度、张力、预设、定位、卡片菜单）全绿；
- 全量：`pnpm test` 95 文件 / 1712 条、UI E2E 65 条。
