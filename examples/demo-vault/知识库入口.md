# 知识库入口

这是示例 Vault 的**导航页**，用来验证 M2/M3 的新能力：

- 双链与反向链接：[[设计文档]]、[[路线图]]
- 标签与属性：本篇的 frontmatter 有 `tags: [示例, 索引]`，正文里还有 #架构 与 #示例/markdown
- 全文搜索：试试搜"原子写"或"虚拟列表"
- 知识图谱：按 `Ctrl+G` —— 这篇会是连接「设计文档」与「路线图」的那个枢纽卡片

## 去哪看什么

| 想看 | 打开 |
| --- | --- |
| 表格 / 围栏代码块的渲染与所见即所得 | [[设计文档]] |
| 长列表、任务复选框（可以直接点） | [[路线图]] |
| 日记类短笔记 | [[2025-01-01]] |
| 本地图片（`![[]]` 与 `![]()` 两种写法） | [[设计文档]] |

> 把光标移进任一 `[[链接]]` 里，编辑器会露出原始标记；移开又变成渲染后的样子 ——
> 这是"所见即所得"的边界：文档始终是纯 Markdown。
