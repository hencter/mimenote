# 示例 Vault

这是一个用来手工验证 M1 闭环的普通文件夹。可以：

1. 直接用它作为 Vault：在应用里「打开文件夹」→ 选择本目录；
2. 或把它复制到别处随便改（它只是普通 Markdown 文件）。

里面刻意包含了几种情况：

| 文件 | 用来验证 |
| --- | --- |
| `README.md` | 基础 Markdown 渲染、中文排版 |
| `知识库入口.md` | **双链与标签的枢纽**：frontmatter `tags` + 正文 `#标签` + 指向多篇的 `[[链接]]`（图谱里它是中心卡片） |
| `写作示例.md` | **写作时的每个能力**：多级标题（大纲面板）、围栏代码块（语言标签 + 复制）、`[[` 补全、`![[]]` 与 `![]()` 两种图片写法、任务列表与嵌套列表 |
| `日记/2025-01-01.md` | 列表、引用、标题层级 |
| `项目/设计文档.md` | 表格、围栏代码块、行内代码、**本地图片**（`![]()` 与 `![[裸文件名]]` 两种写法） |
| `项目/路线图.md` | 嵌套目录、长列表、任务复选框（在编辑器里可以直接点） |
| `附件/示例图片.png` | 本地图片（走 asset 协议逐文件授权） |
| `附件/示例说明.txt` | 非 Markdown 文件（只能选中，不能编辑） |
| `.mimenote/snippets/example.css` | 用户 CSS 片段（状态栏的调色板按钮开关） |

## 手工验证建议

- **所见即所得**：打开 `项目/设计文档.md`，标题/表格/代码块应已渲染；把光标移进某段 `**粗体**` 会露出星号，移开又隐藏。
- **知识图谱**：`Ctrl+G` → `知识库入口` 会是连接两篇的枢纽卡片；点 `路线图` 卡片，**指向它的线是虚线、它指出去的线是实线**。画布 HUD 上的「定位笔记…」可以按名字直达某张卡片（几千张卡片时尤其有用）。
- **大纲面板**：打开 `写作示例.md` → `Ctrl+Shift+O` → 标题树按层级列出，点一条跳到那一行；代码块里的 `# 伪标题` 不在里面。
- **`[[` 补全**：在 `写作示例.md` 末尾敲 `[[` → 弹出笔记列表（`↑↓`/`Enter`/`Esc`），`![[` 之后连附件也会列出来。
- **粘贴图片**：`Win+Shift+S` 截一张 → `Ctrl+V` → 图片落入 `附件/` 并自动插入链接（设置页可改附件目录）；`Ctrl+Z` 能一次撤销。
- **代码块复制**：`Ctrl+E` 切到阅读视图 → 鼠标移到代码块上，右上角出现"复制"按钮与语言标签。
- **搜索命中跳转**：`Ctrl+Shift+F` 搜"原子写" → 回车 → 光标落在命中那一行（该行闪一下）。
- **多标签页**：依次打开两三篇 → 顶部出现标签；`Ctrl+W` 关当前、`Ctrl+1..9` 直达第 N 个；重开应用会回到上次的标签列表。
- **导出**：`Ctrl+Shift+S` 导出 HTML 到桌面 → 断网用浏览器打开，图片也在（内嵌成 `data:`）。
- **标签**：`Ctrl+Shift+T` → 本篇标签与 frontmatter 属性；点某个标签能列出用了它的笔记。
- **换行保真**：用记事本或 VSCode 把某个文件另存为 CRLF，在应用里编辑并保存，再用 `git diff` 看是否只有你改的那几行。
- **冲突检测**：在应用里打开一篇笔记但先不要输入 → 用别的编辑器改同一个文件并保存 → 回到应用里输入一个字 → 应弹出冲突横幅（不会覆盖对方的改动）。
- **删除保护**：删除任意文件 → 出现二次确认；确认后文件出现在 `.mimenote/trash/`，台账在 `.mimenote/index.jsonl`。
- **原子写**：保存时观察目录里是否短暂出现 `.mimenote-*.tmp`（正常结束不应残留）。
- **索引复用**：第一次打开本 Vault 会建索引；关掉再开同一目录应几乎立刻可用（缓存库 `.mimenote/cache/search.db` 被复用）。

## 关于 Git

`.mimenote/` 里放的是应用自己的管理数据（回收站台账、片段、未来的索引）。
如果你用 Git 管理 Vault，建议在 Vault 根目录的 `.gitignore` 里加一行：

```
.mimenote/
```
