# 示例 Vault

这是一个用来手工验证 M1 闭环的普通文件夹。可以：

1. 直接用它作为 Vault：在应用里「打开文件夹」→ 选择本目录；
2. 或把它复制到别处随便改（它只是普通 Markdown 文件）。

里面刻意包含了几种情况：

| 文件 | 用来验证 |
| --- | --- |
| `README.md` | 基础 Markdown 渲染、中文排版 |
| `日记/2025-01-01.md` | 列表、引用、标题层级 |
| `项目/设计文档.md` | 表格、围栏代码块、行内代码 |
| `项目/路线图.md` | 嵌套目录、长列表 |
| `附件/示例说明.txt` | 非 Markdown 文件（M1 只能选中，不能编辑） |
| `.mimenote/snippets/example.css` | 用户 CSS 片段（状态栏的调色板按钮开关） |

## 手工验证建议

- **换行保真**：用记事本或 VSCode 把某个文件另存为 CRLF，在应用里编辑并保存，再用 `git diff` 看是否只有你改的那几行。
- **冲突检测**：在应用里打开一篇笔记但先不要输入 → 用别的编辑器改同一个文件并保存 → 回到应用里输入一个字 → 应弹出冲突横幅（不会覆盖对方的改动）。
- **删除保护**：删除任意文件 → 出现二次确认；确认后文件出现在 `.mimenote/trash/`，台账在 `.mimenote/index.jsonl`。
- **原子写**：保存时观察目录里是否短暂出现 `.mimenote-*.tmp`（正常结束不应残留）。

## 关于 Git

`.mimenote/` 里放的是应用自己的管理数据（回收站台账、片段、未来的索引）。
如果你用 Git 管理 Vault，建议在 Vault 根目录的 `.gitignore` 里加一行：

```
.mimenote/
```
