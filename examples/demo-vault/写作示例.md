# 写作示例

这篇一次覆盖"写作时会用到的每个编辑器能力"，用来手工验收。

## 大纲面板

`Ctrl+Shift+O` 打开右侧大纲 —— 上面那个 `# 写作示例`、这一行的 `##`，以及下面的 `###`
会按层级排成标题树；点任意一条就能跳到那一行（阅读视图里则是滚过去并高亮）。
围栏代码块里的伪标题**不该**出现在大纲里：

```md
# 这行在代码块里，不算标题
```

### 三级标题也在大纲里

## 代码块复制

鼠标移到下面这个代码块上，右上角会出现语言标签与"复制"按钮：

```ts
export function add(a: number, b: number): number {
  return a + b

```

## 双链与补全

输入 `[[` 会弹出当前 Vault 的笔记列表（`↑↓` 选择、`Enter`/`Tab` 确认、`Esc` 取消、
`Ctrl+Space` 手动唤出）；同名多篇时列表里会标出"同名 N"，并把目标写成相对路径。
已有的链接：[[设计文档]]、[[路线图]]、[[知识库入口]]。

## 图片与附件

`![[]]` 嵌入：![[示例图片.png]]

同一张图用**尺寸语法**（Obsidian 的写法）：`![[示例图片.png|120]]` → ![[示例图片.png|120]]

`![]()` 相对路径：![](附件/示例图片.png)

（**别把相对路径写越界**：这篇在 Vault 根目录，所以正确的是 `附件/…`；写成 `../附件/…` 会
指到 Vault 外面，asset 协议**逐文件授权**会拒绝它 —— 图片位置留给一个占位元素，而不是偷偷
显示一个越界文件。`.md` 文件被移进子目录后路径要跟着改，编辑器里的「移动时改写相对链接」会做这件事。）

数字以外的别名是**图注**：![[示例图片.png|一张示例图]]

另外两张是给**尺寸语法**准备的：宽 240 的 `![[示意图.png|240]]` → ![[示意图.png|240]]，
以及 64×64 的小图标按 32 显示 `![[小图标.png|32]]` → ![[小图标.png|32]]（只写宽度时浏览器
按比例缩放，所以改成 `|96` 会看到它变大）。点任意一张图都能放大（灯箱里可以缩放、拖动，
同一篇有多张时用「上一张 / 下一张」或 `PageUp`/`PageDown` 翻页）。

在编辑器里直接 `Ctrl+V` 粘一张截图（或用系统截图工具复制一张），图片会写进 `附件/`
（可在设置页改成别的目录）并自动插入链接 —— 粘贴的瞬间就能看到它。

## 大纲的级别过滤与章节折叠

下面这几节故意做成 `###`/`####` 两层，用来验收大纲面板顶部那排 `H1…H6` 开关与条目左边的三角。
`Ctrl+Shift+O` 打开面板后：点掉 `H4` → 下面四个 `####` 立刻消失（剩余条目的缩进**不跳**）；
把开关全点掉 → 出现「当前过滤条件下没有标题。」与「显示全部级别」；收起「折叠我」那一节 →
它下面两个小节一起消失、**三角仍在**（再点即展开）。

### 折叠我

#### 第一小节

#### 第二小节

### 也折叠我

#### 第三小节

### 平级的一节

折叠上面那节时，这一节**不该**受影响（同级或更浅的标题会终止折叠区间）。

把光标移到被收起的小节里（或按 `Ctrl+E` 切到阅读视图滚到那里）→ 大纲面板顶部会出现
「当前章节（第 N 行）没有显示在列表里」，而**不会**把高亮挪到别的条目上 —— 面板宁可承认
"你看的那一节没显示"，也不告诉你一个错误的方位。换一篇笔记再回来，折叠会恢复成全展开
（折叠刻意不持久化：下次打开要的是完整结构），而级别过滤按 Vault 记住（关掉应用重开仍在）。

## 把 URL 粘到选中的文字上

**先选中下面这行文字，再从浏览器复制一个地址粘上来**：

参考文档

它应该变成 `[参考文档](https://…)`，而不是把选中的文字替换掉 —— 写"参考某某"时不必再手打
`[` `]` `(` `)` 四个符号。粘普通文本（或"见 https://…"这种带说明的一段话）仍然按原本的方式
粘贴，不会自作主张。这条能力由 CodeMirror 的 Markdown 语言包内置提供（默认开启），
所以它跟"粘贴图片"是同一条事件链上**互不干扰**的两件事。

## 标签：面板里直接改

`Ctrl+Shift+T` 打开标签面板：frontmatter 里的标签旁边有 `×`，下面还有一个输入框
（回车提交，一次可以填多个、用逗号分隔）。加一个试试 —— 磁盘上的 `tags:` 会立刻多一项，
而 frontmatter 里其余内容（注释、未知键、换行风格）一个字节都不变；正在编辑的正文
**不会**被覆盖，撤销历史也还在。正文里的 `#标签` 是**只读**的（面板上带「正文」角标），
因为改它就等于改正文。

当前笔记用到的标签：`tags: [示例, 写作]` 加上正文末尾那两个 `#示例 #写作`。
