## 分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 文件层 | `crates/mn-core` | 路径防护、原子写、扫描、回收站 |
| 宿主层 | `apps/desktop/src-tauri` | 会话状态、IPC、错误码 |
| 领域层 | `apps/desktop/src/domain` | 纯函数：树、虚拟列表、EOL、Markdown |
| 状态层 | `apps/desktop/src/state` | zustand store |
| UI 层 | `apps/desktop/src/features` | 组件 |

## 原子写的形状

```rust
let mut tmp = tempfile::Builder::new()
    .prefix(".mimenote-")
    .suffix(".tmp")
    .tempfile_in(dir)?;   // 必须同目录：跨卷 rename 不是原子的
tmp.write_all(bytes)?;
tmp.as_file().sync_all()?;  // 先落盘再改名
tmp.persist(path)?;         // Windows 上是 MoveFileEx(REPLACE_EXISTING)
```

行内代码：`write_atomic(path, bytes)`。

## 冲突处理

1. 读文件时记录 `mtimeMs` 作为版本令牌；
2. 保存时把令牌回传，宿主在写锁内重新 `stat` 比对；
3. 不一致 → 返回 `CONFLICT`，UI 弹出横幅让用户选「覆盖 / 重新加载」；
4. **任何情况下都不静默覆盖用户的文件**。
