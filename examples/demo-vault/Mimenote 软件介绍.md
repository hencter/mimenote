# Mimenote 软件介绍

本地优先、高度可自定义、高性能、交互丝滑的 Markdown 知识库桌面应用。
技术栈：Tauri 2 + Rust + React 19 + TypeScript + CodeMirror 6 + SQLite FTS5。

## 一个 Vault 走完全程

这个示例 Vault 本身就是导游：

- 从 `README.md` 开始（手工验收清单都在里面）；
- `知识库入口` 是双链与标签的枢纽（图谱里它是中心卡片）；
- `写作示例` 覆盖写作时的每个能力（标题/代码/补全/图片/表格/标签/大纲）；
- `项目/Mimenote 专有语法测试` 只放本软件自己加的语法（callout、双链、任务列表）；
- `项目/设计文档` 看表格、代码块与本地图片两种写法；
- `项目/路线图` 看嵌套目录与长列表；
- `日记/2025-01-01` 看列表、引用与标题层级。

## 三个视图，一个真相

左下角状态栏切换：**编辑**（所见即所得，光标进入露原文）、**阅读**（渲染后）、
**图谱**（知识图谱卡片画布）。存下来的永远是纯 Markdown 文件 —— 索引、缓存、
图谱全是可重建的派生数据，删掉 `.mimenote/` 最多损失性能，不损失内容。

## 自定义的四件套

命令（`Ctrl+K`）、快捷键、JSON 主题、Vault 内 `.mimenote/snippets/*.css`
用户样式片段。第三方插件在 M4 起步（manifest + 权限确认 + 示例插件已交付，
动态加载与 Worker 隔离后续）。
