# 架构总览

权威文档是 `docs/architecture.md`；这里只画骨架。

## 分层（自上而下）

UI 层（React，按特性分目录）→ 状态层（Zustand 分片订阅）→ 领域层（纯 TS，
`domain/`，禁 import React/Zustand/Tauri）→ 扩展层（命令注册表 + 快捷键）→
主题层（CSS 变量 + JSON 主题 + 片段）→ IPC 层（可替换适配器）→ 应用层
（Rust：会话状态 + 命令 + 错误码）→ 索引层（`mn-index`：链接/标签/FTS5，
缓存可重建）→ 文件层（`mn-core`：路径防护/原子写/扫描/回收站）。

## 三条铁律

1. `mn-core` / `mn-index` 不依赖 tauri，可独立 `cargo test`；
2. 组件不直接调 IPC（经 store），store 不直接 `invoke`（经 `ipc/client`）；
3. 每个副作用必须可逆（卸载/切 Vault 即清理）。

## 数据流

打开 Vault（一次全量扫描）→ 文件树虚拟化渲染 → `note_read` 进编辑器 →
输入只进 store（零 IO）→ 防抖原子写（mtime 令牌 + 冲突横幅）→ 索引增量同步。
详见 [[开发者手册/索引与搜索]]；命令与错误码见 [[开发者手册/IPC契约]]。
