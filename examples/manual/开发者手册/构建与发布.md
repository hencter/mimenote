# 构建与发布

## 版本号四处同步

`package.json`、`apps/desktop/package.json`、`src-tauri/tauri.conf.json`、
`Cargo.toml`（workspace）—— `node scripts/check-version.mjs` 盯着，
`chore(release)` 提交一次改四处。

## 发版 = 打 tag

`git tag vX.Y.Z && git push origin vX.Y.Z` → Release workflow：
版本校验 → 质量门禁 → 依赖审计 → 打 Windows 安装包（NSIS + MSI）→
发 GitHub Release（自动生成 notes）。托管 runner 跑不了带窗口的 WebView2，
所以应用层 smoke 永远是**本地手动门禁**（发版前在自己机器上跑）。

## 整库导出即 SSG

本手册库就是证明：用应用打开 `examples/manual/` → 整库导出静态站点 →
零 JavaScript 的网站（每篇一个 HTML、双链变相对链接、图片进 `assets/`）。
输出目录必须在 Vault 之外，非空目录凭标记认领，从不删除。
