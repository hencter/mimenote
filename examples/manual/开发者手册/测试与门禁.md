# 测试与门禁

## 四层

1. Rust：`cargo test -p mn-core/mn-index/mimenote`（单元 + 集成 + `#[ignore]` 手工基准）；
2. TS 领域层 + 组件集成（vitest + jsdom，约 100 文件 / 1750 条）；
3. UI E2E（系统 Edge + dist，65 条，真实 Chromium）；
4. 应用层 E2E（release 二进制 + 真实磁盘，34 条 + 5 条 smoke）。

## 门禁（`pnpm check` 一次跑完）

`check:version`（四处版本号一致）→ `check:ipc`（三方契约）→ `typecheck`
（严格模式 + `noUncheckedIndexedAccess`）→ 全量单测 → `cargo test --workspace`，
外加 `clippy -D warnings` 与 `cargo fmt --check`。
CI 另有：macOS 跨平台、依赖安全审计（Rust 全量 / JS 高危+）、Dependabot。

## 验证顺序（本地）

`typecheck` + 目标单测 → `pnpm test` → 动了前端就 `build` + UI E2E →
动了 Rust 才 `tauri build --no-bundle`（3～4 分钟）+ 应用层 E2E。
应用层 smoke（5 条）是**发布前的本地手动门禁**（托管 runner 起不了 WebView2）。

发布流程见 [[开发者手册/构建与发布]]。
