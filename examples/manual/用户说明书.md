# 用户说明书（Mimenote v0.3）

本地优先的 Markdown 知识库：你的笔记是普通文件夹里的普通 `.md` 文件，
本软件只是读写它们的 UI 壳。换句话说 —— **删掉这个软件，你的笔记一字不少**。

## 从哪开始

1. [[用户手册/快速上手]]：打开 Vault、建第一篇笔记、三分钟走完闭环；
2. [[用户手册/写作与编辑]]：所见即所得、Markdown 语法、callout、任务列表；
3. [[用户手册/双链与标签]]：`[[双链]]`、反向链接、标签与属性；
4. [[用户手册/搜索与图谱]]：全文搜索、命中跳转、知识图谱；
5. [[用户手册/导出与发布]]：自包含 HTML、打印 PDF、整库静态站点；
6. [[用户手册/设置与同步]]：主题字号、附件目录、时间戳保护、同步盘注意事项；
7. [[用户手册/快捷键速查]]：一张表查所有快捷键。

写东西出了问题先看 [[开发者说明书]]（同一目录下）：架构、契约、测试门禁都在那里。
