# 快速上手

## 1. 打开一个 Vault

Vault 就是一个文件夹。首次启动选"打开文件夹"，指向你的笔记目录
（同步盘目录也可以，但请把 `.mimenote/` 排除出同步 —— 那是可丢弃的派生数据）。

## 2. 建第一篇笔记

文件树工具栏点 `+`（`Ctrl+N`），输入标题回车。编辑器是所见即所得：
写 `**粗体**` 直接变粗，把光标移进去才露出星号 —— 存下来的永远是纯 Markdown。

## 3. 走完闭环

写两行 → 等半秒（状态栏显示"已保存"与写入耗时）→ 左下角切**阅读**看渲染 →
文件树右键删除 → 进 `.mimenote/trash`（可恢复）。这就是 M1 最小闭环。

阅读用来看，图谱用来找关系。
