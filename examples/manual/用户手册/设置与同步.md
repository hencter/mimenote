# 设置与同步

## 设置页（`Ctrl+,`）

外观（主题：深色/浅色/纸墨；三档字号）、编辑器（自动保存延迟、Tab 宽度、
行号、附件目录）、Vault（CSS 片段、时间戳保护、索引与缓存）、关于。
全部即时生效，不重建编辑器。

## 主题与 CSS 片段

颜色全部来自令牌：换主题 JSON 即可换肤；`.mimenote/snippets/*.css`
放你自己的样式（开关在 Vault 分区，关掉整体卸载；只读你自己的 Vault，不加载远程）。

## 同步盘注意事项

Vault 放同步盘（坚果云等）完全可以，但请**排除 `.mimenote/`**（索引缓存，
200MB 级，反复上传浪费流量；删掉下次打开自动重建）。

外部改动（手机上改了一笔）会自动同步：约半秒后文件树刷新，当前笔记无未保存修改
则跟随磁盘，有则进冲突横幅（覆盖 / 重新加载二选一，绝不静默覆盖）。

## 时间戳保护（可选，默认关）

同步传递经常丢文件 mtime。打开后，新建时写入 `created` / `updated`
（UTC），每次保存刷新 `updated`，`created` 永不覆盖；没有 frontmatter 的旧笔记
不擅自建块。时间跟着正文走，内容到了时间就到了。
