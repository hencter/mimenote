# 导出与发布

## 单篇导出

文件树工具栏点**导出**：自包含 HTML（图片内嵌，浏览器直接打开），
或打印/另存为 PDF（走系统打印对话框）。这是唯一允许写 Vault 之外的写操作，
且只接受 `.html` 文件。

## 整库静态站点

把整个 Vault 导出成一个**零 JavaScript** 的网站：每篇一个 HTML、双链变相对链接、
图片复制进 `assets/`、共享样式表 + 索引页。输出目录必须在 Vault 之外，
非空目录凭标记文件认领（从不删除任何文件），两次导出逐字节相同。

**本手册就是这么发布的**：用本应用打开 `examples/manual/`，整库导出，
得到的就是网站（参考 [[开发者手册/构建与发布]]）。

## 回收站

删除进 Vault 内 `.mimenote/trash`（可见、可恢复、可"恢复为…"）。
清空请去文件管理器手动做（台账会标出孤儿记录）。
