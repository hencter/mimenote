# 快捷键速查

`Mod` = Ctrl（macOS 上是 Cmd）。命令面板（`Ctrl+K`）能搜到全部， JetBrains 式遗忘也没关系。

| 按键 | 动作 |
| --- | --- |
| `Ctrl+P` | 快速切换（按名直达笔记） |
| `Ctrl+K` | 命令面板 |
| `Ctrl+Shift+F` | 全文搜索 |
| `Ctrl+Shift+T` | 标签面板 |
| `Ctrl+Shift+O` | 大纲面板 |
| `Ctrl+Shift+L` | 链接面板 |
| `Ctrl+G` | 知识图谱 |
| `Ctrl+E` | 编辑 / 阅读循环切换 |
| `Ctrl+,` | 设置页 |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+S` | 立刻保存（自动保存之外） |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+1..9` | 直达第 N 个标签 |
| `F2` | 重命名选中项 |
| `F6` | 移动到文件夹 |
| `Ctrl+Alt+R` | 重新扫描 Vault |
| `Mod+Alt+F` | 表格对齐格式化 |
| `Ctrl+Space` | 在 `[[` 上下文里手动唤出补全 |
| `Esc` | 关浮层 / 关弹层 / 关设置 |

文件树上 `Ctrl/⌘+点击` 或中键 = 在新标签里打开（默认顶掉当前标签）。
